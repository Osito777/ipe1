# Test IPE1 · UD1 Prevención de riesgos laborales

Test de 100 preguntas (3 alternativas) con Streamlit. Incluye los casos especiales vistos en clase.

## Ejecutar en local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar
1. Sube `app.py`, `preguntas.py` y `requirements.txt` a un repo de GitHub.
2. En https://share.streamlit.io elige el repo y `app.py` como archivo principal.

Para añadir preguntas, edita `preguntas.py` (formato: tema, pregunta, correcta, [2 incorrectas], explicación).
